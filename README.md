# Pandas Learning Notes

A collection of beginner-friendly notes, examples, and practical exercises for learning **Pandas**, a Python library used for data manipulation and analysis.

This repository contains Jupyter Notebooks with explanations in Markdown cells and executable Python code cells.

## Topics Covered

### 1. DataFrame Column Operations
- Creating a DataFrame using `pd.DataFrame()`
- Adding columns using `insert()`
- Removing columns using `pop()`
- Deleting columns using `del`

### 2. CSV File Handling with Pandas
- Reading CSV files using `pd.read_csv()`
- Understanding CSV parameters
- Selecting and filtering data
- Sorting and grouping records
- Handling missing values and duplicates
- Cleaning data and converting data types
- Exporting data using `to_csv()`
- Practical sales analysis examples


## Requirements

- Python 3
- Jupyter Notebook or Google Colab
- Pandas

Install Pandas using:

```bash
pip install pandas
```

## How to Use

1. Clone or download this repository.
2. Open a notebook using Jupyter Notebook, JupyterLab, or Google Colab.
3. Read the explanations in the Markdown cells.
4. Execute the Python code cells to understand each concept.

## Practical Applications

The examples demonstrate how Pandas can be used for:

- Sales and revenue analysis
- Data cleaning and preparation
- Missing-value and duplicate handling
- Data summarization and reporting
- Preparing datasets for further analysis

## Goal

My goal is to build a strong foundation in Pandas and Python data analysis through structured notes, hands-on coding, and practical examples.
